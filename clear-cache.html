2. Limpeza Manual (Recomendado)

Para uma limpeza mais completa, siga estes passos:

  • Chrome/Edge: Ctrl+Shift+Delete → Selecionar "Todo o período" → Marcar todas as opções → Limpar dados
  • Firefox: Ctrl+Shift+Delete → Selecionar "Tudo" → Marcar todas as opções → Limpar agora
  • Safari: Cmd+Option+E → Desenvolver → Esvaziar caches
